# 가챠 TTS

**Gacha Forge TTS** · Marinara Engine 개인 확장 · v0.1.0

가챠 포지 스토리 대사를 ElevenLabs 음성으로 읽어 주는 확장입니다. 보이스는 월드마다 따로 정하고, 공용 로어북 하나를 월드에 연결해 AI가 대사에 감정 태그(`[happy]`, `[whispers]` 등)를 넣게 합니다.

> 비공식 개인 프로젝트입니다. 가챠 포지 저장 데이터는 바꾸지 않습니다. 월드 로어북 설정에는 이 확장의 로어북을 추가하거나 빼는 것만 합니다.

참고한 확장: [TTS-11LABS-ADD](https://github.com/marittini/TTS-11LABS-ADD)(마리나라 TTS로 음성 요청), [Gacha-Forge-Quest-Extension](https://github.com/tlsiddl/Gacha-Forge-Quest-Extension)(가챠 포지 통신 관찰, 월드 로어북 연결).

## 준비물

- Marinara Engine과 Gacha Forge
- 마리나라 **연결 → TTS**에서 ElevenLabs를 켜 두기. API 키는 마리나라 서버가 갖고 있고, 이 확장은 키를 읽거나 저장하지 않습니다.
- 감정 태그를 쓰려면 `eleven_v3` 이상의 모델을 권장합니다. TTS 설정의 **대괄호 텍스트 건너뛰기**가 켜져 있으면 태그가 전달되지 않습니다. 공통 탭에서 끌 수 있습니다.

가챠 포지 화면 상단바에 버튼 두 개가 생깁니다.

- **스피커 버튼**: 현재 대사를 다시 듣거나, 재생 중이면 멈춥니다.
- **설정 버튼**: 가챠 TTS 창을 엽니다.

## 사용 방법

1. 가챠 포지에서 월드를 열고 스토리를 진행합니다. 월드와 장면에 나온 화자가 자동으로 기록됩니다.
2. **설정** 탭 왼쪽 목록에서 월드를 고르고, 인물별 보이스를 지정합니다. ▶로 미리 들어볼 수 있습니다.
   - **기본 보이스**: 보이스를 지정하지 않은 인물에게 쓸 목소리. 비워 두면 그런 인물은 읽지 않습니다.
   - **내레이션도 읽기**: 켜고 내레이터 보이스를 고르면 지문도 읽습니다.
   - **끔**: 특정 인물만 읽지 않습니다.
3. 이후 대사가 화면에 나오면 해당 인물의 목소리로 자동 재생됩니다.

## 감정 태그 로어북

- 처음 월드에 들어오면 공용 로어북 **가챠 TTS · 음성 감정 태그**를 한 번 만들고, 그 월드의 가챠 포지 로어북 설정 **맨 앞**에 연결합니다(스토리 장면에도 사용). 기존 로어북과 예산은 그대로 둡니다.
- 자동 연결은 월드마다 한 번만 합니다. 나중에 가챠 포지에서 직접 뺐다면 다시 넣지 않습니다. 설정 탭의 **지금 연결 / 연결 해제**로 바꿀 수 있습니다.
- 로어북 내용은 확장이 덮어쓰지 않으니, 마리나라 로어북 화면에서 자유롭게 고쳐도 됩니다.
- 로어북 대신 스토리 지침에 넣고 싶다면 공통 탭의 **지침용 문구 복사**를 쓰고, 월드 설정에서 감정 태그 로어북 사용을 끄세요.
- AI가 넣은 영어 소문자 태그(`[happy]` 형태)는 화면에서 숨기고 음성에만 보냅니다. `[시스템]` 같은 한글 대괄호는 건드리지 않습니다.

## 데이터

- 설정은 브라우저 `localStorage`의 `gf-tts-v1`에 저장되고, 마리나라 확장 저장소(`marinara.storage`)로 다른 기기와 동기화됩니다.
- 만든 음성은 이 탭에서만 최근 60개를 기억합니다. 같은 대사를 다시 들어도 요금이 다시 들지 않습니다.
- **다음 대사 미리 만들기**를 켜면 응답이 빨라지지만, 건너뛴 대사도 요금이 듭니다(기본 꺼짐).

## 한계

- 화면에 보이는 대사와 가챠 포지가 받은 장면 데이터를 글자로 맞춰 화자를 찾습니다. 장면 데이터를 받기 전에 저장된 화면을 그대로 띄우면 인식하지 못할 수 있습니다. 그럴 땐 장면을 다시 열어 주세요.
- 실제 가챠 포지 화면 구조를 흉내 낸 jsdom 테스트(`tests/ui.test.js`)만 통과했습니다. 실제 서버와 ElevenLabs 유료 생성으로는 확인하지 않았습니다.
