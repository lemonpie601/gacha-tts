# 가챠 TTS

**Gacha Forge TTS** · Marinara Engine 개인 확장 · v0.6.1

가챠 포지 스토리 대사를 ElevenLabs 음성으로 읽어 주는 확장입니다. 보이스는 월드마다 따로 정하고, 공용 로어북 하나를 월드에 연결해 AI가 대사에 감정 태그(`[happy]`, `[whispers]` 등)를 넣게 합니다.

> 비공식 개인 프로젝트입니다. 가챠 포지 저장 데이터는 바꾸지 않습니다. 월드 로어북 설정에는 이 확장의 로어북을 추가하거나 빼는 것만 합니다.

참고한 확장: [TTS-11LABS-ADD](https://github.com/marittini/TTS-11LABS-ADD)(마리나라 TTS로 음성 요청), [Gacha-Forge-Quest-Extension](https://github.com/tlsiddl/Gacha-Forge-Quest-Extension)(가챠 포지 통신 관찰, 월드 로어북 연결).

## 준비물

- Marinara Engine과 Gacha Forge
- 마리나라 **연결 → TTS**에서 ElevenLabs를 켜 두기. API 키는 마리나라 서버가 갖고 있고, 이 확장은 키를 읽거나 저장하지 않습니다.
- 감정 태그를 쓰려면 `eleven_v3` 이상의 모델을 권장합니다. TTS 설정의 **대괄호 텍스트 건너뛰기**가 켜져 있으면 태그가 전달되지 않습니다. 설정 → TTS 화면에서 끌 수 있습니다.

## 설치

GitHub 확장 관리자에 아래 주소를 등록해 설치·활성화합니다.

```text
https://github.com/lemonpie601/gacha-tts
```

설치하면 두 곳이 바뀝니다.

- **가챠 포지 설정 화면 왼쪽 목록**에 **음성 · TTS** 항목이 생깁니다. 지금 플레이 중인 월드의 보이스 설정이 게임 화면 그대로의 모양으로 열립니다.
- **스토리 화면 도구 막대**(자동·넘기기·기록) 맨 앞에 **듣기** 버튼이 생깁니다. 현재 대사를 듣고, 재생 중에는 **멈춤**으로 바뀝니다. 이미 만든 음성은 다시 들어도 요금이 들지 않습니다.

## 사용 방법

1. 가챠 포지에서 월드를 열고 스토리를 진행합니다. 월드와 장면에 나온 화자가 자동으로 기록됩니다.
2. 가챠 포지 **설정 → TTS**에서 인물별 보이스를 지정합니다. 설정은 지금 플레이 중인 월드에만 저장되므로, 월드마다 따로 정할 수 있습니다. ▶로 미리 들어볼 수 있습니다.
   - **기본 보이스**: 보이스를 지정하지 않은 인물에게 쓸 목소리. 비워 두면 그런 인물은 읽지 않습니다.
   - **내레이션도 읽기**: 켜고 내레이터 보이스를 고르면 지문도 읽습니다.
   - **끔**: 특정 인물만 읽지 않습니다.
   - **조절**: 인물별 음량(0~150%)과 속도(×0.5~×2)를 정합니다(v0.6.0). 내레이터도 같은 화면에서 정할 수 있습니다. 재생 속도만 바꾸므로 음높이는 그대로이고, 음성을 다시 만들지 않아 요금이 들지 않습니다. 재생 중에 끌면 바로 반영됩니다. 100%를 넘는 음량은 브라우저 Web Audio로 키우며, 쓸 수 없는 환경에서는 100%로 재생합니다.
3. 같은 화면의 **대사 자동 재생**을 켜 두면 대사가 나올 때마다 바로 읽고, 끄면 **듣기** 버튼을 누를 때만 읽습니다. 월드마다 따로 저장됩니다.

## 감정 태그 로어북

- 처음 월드에 들어오면 공용 로어북 **가챠 TTS · 음성 감정 태그**를 한 번 만들고, 그 월드의 가챠 포지 로어북 설정 **맨 앞**에 연결합니다(스토리 장면에도 사용). 기존 로어북과 예산은 그대로 둡니다.
- 자동 연결은 월드마다 한 번만 합니다. 나중에 가챠 포지에서 직접 뺐다면 다시 넣지 않습니다. 설정 → TTS의 **지금 연결 / 연결 해제**로 바꿀 수 있습니다.
- 지침 내용 (v0.4.0):
  - **태그 범위**: 태그는 다음 태그가 나올 때까지 말투를 계속 바꾸므로, 고함·속삭임·울음 같은 강한 태그는 그 구절에만 쓰고 끝나면 본래 감정 태그로 되돌리게 합니다. (예: `[shouts] 멈춰! [tense] …지금 움직이면 다 무너져.`)
  - **개수**: 대사 첫머리에 하나, 이후 감정·강도·말투가 바뀌는 문장마다 하나씩. 세 개 제한은 없앴습니다.
  - **세분화**: 감정 10갈래(기쁨, 애정·장난, 수줍음, 불안, 슬픔, 분노, 냉담, 진지, 놀람, 지침)와 말투·소리·쉼 태그 약 100개, 강도 단계(짜증 → 화남 → 격분 등)를 안내합니다.
- 로어북을 직접 고치면 확장이 덮어쓰지 않습니다. 예전 버전이 만든 지침을 그대로 두셨다면 새 지침으로 자동으로 바뀝니다. 고친 뒤에도 **기본 지침으로 바꾸기**로 최신 지침을 다시 받을 수 있습니다.
- 로어북 대신 스토리 지침에 넣고 싶다면 **지침용 문구 복사**를 쓰고, 같은 화면에서 감정 태그 로어북 사용을 끄세요.
- AI가 넣은 영어 소문자 태그(`[happy]` 형태)는 화면에서 숨기고 음성에만 보냅니다. `[시스템]` 같은 한글 대괄호는 건드리지 않습니다.

## Gacha Choice(대답 선택지)와 함께 쓸 때

- 선택지를 고른 뒤 나오는 답 대사(대사 번호가 그대로인 1~3줄)도 인물별 보이스로 읽습니다 (v0.5.1).
- 답 대사에 들어간 감정 태그도 화면에서 숨깁니다.

## 알림 창

확인·입력 창과 알림은 브라우저 기본 팝업 대신 게임 화면 안에 직접 그립니다. 그래서 전체 화면이 풀리지 않습니다.

## 데이터

- 설정은 브라우저 `localStorage`의 `gf-tts-v1`에 저장되고, 마리나라 확장 저장소(`marinara.storage`)로 다른 기기와 동기화됩니다. 보이스·설정은 항목별로 마지막에 바꾼 쪽이 남고(v0.5.1), 다른 기기에서 바꾼 보이스는 20초 안에 새로고침 없이 반영됩니다.
- **만든 음성은 마리나라 서버에 저장됩니다** (v0.5.0, 기본 켜짐). 같은 보이스와 같은 대사(태그 포함)는 새로고침하거나 다른 기기에서 열어도 서버에서 불러오고 다시 만들지 않습니다.
  - 저장 위치: 마리나라 데이터 폴더의 `game-assets/sfx/.gacha-tts/`. 점(.)으로 시작하는 폴더라 게임 효과음·음악 목록에는 나오지 않습니다.
  - 용량을 정리하려면 이 폴더를 통째로 지우면 됩니다. 지운 대사는 다음에 다시 만듭니다.
  - 설정 → TTS의 **만든 음성을 서버에 저장**으로 끌 수 있습니다. TTS 모델을 바꿔도 이미 저장된 대사는 예전 음성을 그대로 씁니다.
  - 마리나라 **TTS 속도**를 바꾸면 그 속도로 새로 만듭니다(v0.6.1). 속도 1.0은 예전 저장 음성을 그대로 쓰고, 다른 속도는 따로 저장됩니다. `eleven_v3`는 마리나라가 속도를 보내지 않는 모델이라 속도를 바꿔도 새로 만들지 않습니다.
- 한 번 연 화면 안에서는 최근 60개를 메모리에도 들고 있어 서버에 다시 묻지 않습니다.
- **다음 대사 미리 만들기**를 켜면 응답이 빨라지지만, 건너뛴 대사도 요금이 듭니다(기본 꺼짐).

## 한계

- 화면에 보이는 대사와 가챠 포지가 받은 장면 데이터를 글자로 맞춰 화자를 찾습니다. 장면 데이터를 받기 전에 저장된 화면을 그대로 띄우면 인식하지 못할 수 있습니다. 그럴 땐 장면을 다시 열어 주세요.
- 실제 가챠 포지 화면 구조를 흉내 낸 jsdom 테스트(`tests/ui.test.js`)만 통과했습니다. 실제 서버와 ElevenLabs 유료 생성으로는 확인하지 않았습니다.
